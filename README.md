# AIDA64 Real-Time Web Dashboard (Telemetry Monitor System)

Telemetry Monitor System — это веб-интерфейс и локальный сервис мониторинга аппаратных компонентов компьютера в реальном времени. Проект создан как облегченный веб-аналог системных утилит вроде AIDA64 или CPU-Z.

Приложение извлекает низкоуровневую информацию о комплектующих через подсистему Windows Management Instrumentation (WMI), обрабатывает данные на бэкенде FastAPI и отдает их на динамический дашборд.

---

## Основные возможности

### Мониторинг и автоматическое обновление
* **Auto-Polling без перезагрузки:** Клиентский интерфейс автоматически запрашивает свежие данные у REST API каждые 3 секунды через асинхронные fetch()-запросы.
* **Индикация активности:** Визуальный пульсирующий индикатор (Live Status) на панели управления информирует о статусе подключения.
* **Ручное обновление:** Возможность мгновенно запросить текущие данные по кнопке «Обновить».

### Детальная спецификация оборудования
1. **Процессор (CPU):**
   * Полное наименование и архитектура.
   * Количество физических ядер и логических потоков.
   * Базовая и максимальная тактовая частота (в MHz).
   * Тип процессорного разъема (Socket).
   * Объем кэш-памяти L2 и L3.
2. **Оперативная память (RAM):**
   * Детализация по каждому физическому модулю (DIMM).
   * Объём (ГБ), заявленная и сконфигурированная частота (МГц).
   * Производитель, серийный номер и партийный номер (Part Number).
   * Рабочее напряжение и расположение на материнской плате (Bank/Device Locator).
3. **Графический адаптер (GPU):**
   * Модель видеокарты и тип видеопроцессора.
   * Версия и дата установленного видеодрайвера.
   * Объем видеопамяти (VRAM) и тип ЦАП (DAC).
   * Текущее разрешение и частота обновления экрана.
4. **Накопители (SSD / HDD):**
   * Модель диска и объем (ГБ).
   * Тип интерфейса (NVMe, SATA, USB).
   * Версия прошивки (Firmware Revision), серийный номер и количество разделов.
5. **Материнская плата и система:**
   * Название производителя и точность ревизии платы.
   * Серийный номер и версия BIOS.
   * Версия и номер сборки операционной системы Windows.

## Архитектура и Технологии

### Backend
* **Python 3.10+** — основной язык разработки.
* **FastAPI** — высокопроизводительный веб-фреймворк для создания REST API.
* **Uvicorn** — ASGI-сервер для обработки асинхронных веб-запросов.
* **WMI & PyWin32** — библиотеки для взаимодействия с Windows Management Instrumentation API и получения системных метрик.

### Frontend
* **HTML5 & CSS3** — адаптируемая верстка на базе Flexbox и CSS Grid.
* **Dark Theme Design** — современный тёмный интерфейс с акцентной подсветкой элементов.
* **Vanilla JavaScript (ES6+)** — обработка AJAX-запросов, динамический DOM-манипулятор без использования тяжелых фреймворков.
