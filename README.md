# 🖥️ AIDA64 Real-Time Web Dashboard

Веб-приложение для мониторинга и получения подробных аппаратных спецификаций компьютера в режиме реального времени. Проект собирает данные через Windows Management Instrumentation (WMI) и отображает их в интерактивном веб-интерфейсе.

---

## 🌟 Основные возможности

* **Мониторинг в реальном времени:** Автоматическое обновление данных без перезагрузки страницы (polling через AJAX каждые 3 секунды).
* **Сбор WMI-данных:**
  * **Процессор (CPU):** наименование, число ядер/потоков, тактовая частота, сокет, размер кэш-памяти L2/L3.
  * **Оперативная память (RAM):** подробные характеристики каждого DIMM-модуля (объем, частота, производитель, артикул/Part Number, серийный номер, напряжение).
  * **Видеокарта (GPU):** модель, версия драйверов, разрешение, объем видеопамяти.
  * **Накопители (SSD/HDD):** модель, объем, тип интерфейса, серийный номер, версия прошивки.
  * **Материнская плата:** производитель, модель, версия BIOS/платы, серийный номер.
* **Интерактивный UI:** Раскрывающиеся списки (`<details>`) для просмотра глубоких спецификаций каждого элемента железа.

---

## 🛠️ Технологический стек

* **Backend:** Python 3.10+, FastAPI, Uvicorn, `wmi`, `pywin32`
* **Frontend:** HTML5, CSS3 (Modern Flexbox/Grid, Dark Theme), JavaScript (Async/Fetch API)

## 🚀 Инструкция по запуску

### 1. Требования
* Операционная система **Windows 10 / 11** (необходима поддержка WMI).
* Установленный **Python 3.10+**.

### 2. Установка зависимостей
Откройте PowerShell в папке проекта и установите необходимые библиотеки:
bash
pip install fastapi uvicorn wmi pywin32### 3. Запуск приложения
Запустите сервер FastAPI:
bash
python -m uvicorn backend.main:app --reload
После успешного запуска откройте браузер и перейдите по адресу:
👉 **[http://127.0.0.1:8000/](http://127.0.0.1:8000/)**
